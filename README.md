# AetherML — Interactive Machine Learning Lab

A beautiful, fully functional **browser-based ML sandbox** where you can draw data points, train multiple ML models live, see real-time decision boundaries, and export clean Python + scikit-learn projects.

### ✨ Features
- Interactive canvas (draw, brush, erase data points)
- Support for **Classification, Regression & Clustering**
- 6+ ML models: Neural Network, SVM, Decision Tree, KNN, Logistic Regression, K-Means
- Real-time decision boundary visualization
- Side-by-side model comparison (3 models at once)
- Feature engineering, noise control, CSV upload with column mapping
- Session save / load
- One-click Python project exporter
- Clean, modern minimalist UI

### How to Use
Just open **`ml_data_mapper.html`** in any modern browser — **no installation needed**.
