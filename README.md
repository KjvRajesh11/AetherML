# AetherML — Interactive Machine Learning Lab

A beautiful, fully functional **browser-based ML sandbox** where you can draw data points, train multiple ML models live, see real-time decision boundaries, and export clean Python + scikit-learn code.

### ✨ Features
- Interactive canvas (draw, brush, erase)
- Classification, Regression & Clustering support
- 6+ ML models (Neural Network, SVM, Decision Tree, KNN, Logistic Regression, K-Means)
- Real-time decision boundary visualization
- Side-by-side model comparison
- Feature engineering, noise control, train/test split
- CSV upload with column mapping
- Session save/load
- One-click Python project exporter

### Tech Stack
- HTML5 Canvas + Vanilla JavaScript
- Custom ML implementations (backpropagation, SVM, Decision Trees, etc.)
- Chart.js for metrics

### How to Use
Just open `ml_data_mapper.html` in any browser. No installation required.
